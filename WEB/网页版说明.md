# 生图网页版

浏览器里生图，不用改代码。`image2.5.py` 和 `test.py` 保持原样，两条路都能走。

## 怎么开

双击 **`启动.bat`**，会自动打开 <http://127.0.0.1:8765>。
第一次用先双击一次 **`安装依赖.bat`**。

PyCharm 里也可以：Run Configuration 指向 `app.py`，解释器选 Python 3.13 那个。
工作目录随便设，代码里的路径都是从文件位置推导的。

关掉那个黑窗口就是关闭服务。

## 界面

- **文生图 / 图生图** 两个标签页。图生图会多出参考图上传区。
- 参考图**顺序有意义** —— 模型按顺序理解「图 1 / 图 2」，和 `image2.5.py` 里
  `INPUT_IMAGES` 列表的顺序是一回事。用 ▲ ▼ 调整，✕ 删除。
- **模型线路**：候选是 `-sunburst` / `-flare` / 裸名（`gpt-image-2.5`），互为备份。
  主线路遇到限流、5xx 或超时会自动换下一条；内容被拦、额度不够这类错误换线路
  也没用，会直接报错。任务卡片上会显示「你选的 → 实际用的」。
- 生成中可以**继续提交**，超出的排队（最多 2 个同时跑，再排 4 个）。
- 输出文件名可以留空。同名不会覆盖，会自动加 `_2` `_3`。

## 设置

页面**左下角的「⚙ 设置」**，里面三项，改完点保存就生效、重开还在：

- **图片保存位置** —— 可以点「浏览…」弹 Windows 原生文件夹框，也可以直接粘贴路径。
  留空 = 用默认目录。改完历史立刻从新位置读。
- **API key** —— 输入框默认是密码态，点「显示」能看到完整值（方便忘了自己的 key）。
- **接口地址（base_url）** —— 你的 key 和请求会发到这个地址。默认是
  `https://api.a6api.com/v1`，换中转/代理服务时改这里。留空 = 用默认。
  一般要以 `/v1` 结尾（OpenAI SDK 会在这个地址后面接 `/images/generations`）；
  填了不带 `/v1` 的地址不会拦你，但保存时会弹一句提醒。

三项都存在 `WEB/settings.json`，那个文件被 `.gitignore` 排除，不会上传。
`settings.json.example` 是模板，一般用不着。

> ⚠ 改了接口地址之后，**你的 API key 就会发到那个地址去**。这是这个功能的
> 本意（用中转服务时 key 本来就要给对方），但别把地址改成来路不明的东西。

**换目录不会移动旧文件**：原来那个文件夹原封不动，只是界面上不再显示它，
想找旧图直接去旧文件夹。这样设计是为了避开「搬到一半失败」和「把别的文件夹里
的东西挪走」这类事故。

几个边界：路径不存在会自动创建；盘符根目录（`C:\`）会被拒绝，因为历史是扫目录的，
指到根会把整块盘翻一遍；路径写不进去（没权限、只读盘、盘满）会当场报错，
**而且当前生效的目录一点都不会被改坏**。

如果 `settings.json` 被手改坏了（比如少了个引号），服务照样能启动：按默认值跑，
坏文件会被改名成 `settings.json.corrupt` 留着，控制台有警告。

## 图存到哪

**默认是 `P5\image\aipicture\年月日\`** —— 也就是 `image2.5.py` 一直在用的那棵树，
两边共用，所以脚本生成的图也会出现在网页的历史里。历史是直接扫目录的，
不维护索引文件，`aipicture\` 里除了图片不会多出任何东西，你手动删图、手动放图
都能正确反映。

想换地方就在**网页左下角的「设置」里改**（推荐，不懂代码的人也能自己弄）。
脚本版 `image2.5.py` 始终写它自己所在目录下的 `aipicture/`，**不跟随网页设置** ——
换过目录之后，网页历史和脚本产出的图就不再是同一份了。

临时覆盖（优先级低于设置面板，开发调试用）：

```bat
set A6_OUTPUT_DIR=D:\别的地方\aipicture
```

启动时横幅会打印实际用的目录**以及这个值从哪来**（设置 / 环境变量 / 默认），
看一眼就知道对不对。

## 调界面时用 MOCK 模式

真调用一次要 60~300 秒，调界面会疯掉。把 `启动.bat` 里那行 `set A6_MOCK=1`
的 `rem` 去掉，就会用 Pillow 本地画假图，秒级返回：

```bat
set A6_MOCK=1
```

| 环境变量 | 作用 |
| --- | --- |
| `A6_MOCK=1` | 不真调接口，本地画假图 |
| `A6_MOCK_DELAY=20` | 假图也等 20 秒，用来验证「排队中 / 生成中」和并发 |
| `A6_MOCK_FAIL=1` | 让任务必定失败，用来验证错误提示的显示 |
| `A6_PORT=8765` | 换端口 |
| `A6_MAX_CONCURRENCY=2` | 同时最多几个调用 |
| `A6_MAX_QUEUE=4` | 再排几个队，超出直接拒 |
| `A6API_KEY=sk-...` | 临时指定 key，**注意没有下划线**（老文档里写成 `A6_API_KEY` 是错的，那个名字代码根本不读）。平时用设置面板，别设它 |
| `A6_OUTPUT_DIR=...` | 临时换输出目录；优先级低于设置面板 |
| `A6_BASE_URL=...` | 临时换接口地址；优先级低于设置面板 |
| `A6_NO_BROWSER=1` | 启动时不自动开浏览器 |

`A6API_KEY`、`A6_OUTPUT_DIR`、`A6_BASE_URL` 的优先级都是「网页设置 > 环境变量 > 内置默认」。
启动横幅会告诉你当前用的是哪个。

## 升级依赖前先跑自检

```
python selftest.py
```

`a6.py` 里那段 `FieldNameClient` 靠**字节替换** `name="image[]"` 来适配服务端的
两种字段名要求。这个字段名来自 openai 内部 `extract_files` 的 `array_format`
默认值，而 httpx 的 multipart 编码行为决定了替换后能不能正常工作。

**任何一边变了，代码都不会报错，只会静默发错字段名 → 服务端回 400。**
`selftest.py` 就是盯这两件事的。所以 `requirements.txt` 里 `openai` 和 `httpx`
是钉死的版本，升级前先跑自检。

## 几个要知道的

1. **只监听 127.0.0.1。** 不要改成 `0.0.0.0` —— 那等于把无鉴权的生图接口
   暴露给整个局域网，同 WiFi 下任何人都能烧你的额度。真要给别人用，
   起码先加个口令。
2. **key 不在代码里。** 网页版存在 `WEB/settings.json`，在网页左下角的设置里改；
   脚本版 `image/` 则是读同目录的 `image/env.py`。两个文件都被 `.gitignore` 排除，不会上传。
   （`key.bat` 那套已经废弃了。`启动.bat` 只在第一次迁移时读它一次，把 key 搬进
   `settings.json`，之后就再也不看了 —— 你可以放心把它删掉。）

   设置里点「显示」能看到完整 key，这是**有意做的**：本机自用，忘了 key 能当场查。
   代价是本机页面能拿到明文，所以**服务只能监听 127.0.0.1**。一旦要对外暴露，
   必须先删掉 `app.py` 里的 `/api/settings/api-key` 端点。
3. **重启后正在跑的任务会消失。** 任务表在内存里。已经落盘的图不受影响，
   会出现在历史里。
4. **取消是尽力而为。** 请求已经发出去就收不回来了，线程也杀不掉 ——
   取消只能让结果不被采纳，**省不下这一次调用和额度**。界面上也是这么写的。
5. **Ctrl+C 可能要等。** 有任务在跑时，正常退出会等它结束（最长 300 秒）。
   再按一次强制退出。
6. **`a6.py` 和 `image2.5.py` 里的字段名兼容逻辑是两份拷贝**。服务端再改接口时，
   两处都要改。（原先约定 `image2.5.py` 一字不改，2026-10-12 为去掉硬编码 key 破了例。）

## 文件

| 文件 | 作用 |
| --- | --- |
| `a6.py` | 客户端层：建连接、调接口、重试、存图、扫历史 |
| `app.py` | FastAPI 服务：任务表、线程池、路由 |
| `settings_store.py` | 用户设置（保存位置 / API key / 接口地址）的读写与校验 |
| `static/` | 前端（原生 JS，无构建步骤） |
| `selftest.py` | 依赖升级后的金丝雀自检 |
| `启动.bat` / `安装依赖.bat` | 双击用 |
| `settings.json` | 你的设置（含 key）。被 `.gitignore` 排除，不会上传。模板是 `settings.json.example` |
| `key.bat` | **已废弃**，只在首次启动时被读一次用于迁移 key，之后可以删 |
| `requirements.txt` | 依赖 |

## 接口

自己写脚本调也可以：

```
GET  /api/config                 可用模型、尺寸、上限、当前设置来源
POST /api/generate               multipart → {task_id}
GET  /api/tasks/{id}             状态、耗时、结果
POST /api/tasks/{id}/cancel      尽力而为
GET  /api/tasks                  最近的任务
GET  /api/history?limit=&offset= 扫目录得到的历史
GET  /images/<日期>/<文件名>      图片本体（按当前设置的目录实时找，不是启动时挂载的）
GET  /api/settings               当前设置。key 只给掩码
GET  /api/settings/api-key       ⚠ 完整 key 明文，仅供「显示」按钮
POST /api/settings               保存设置 {output_dir?, api_key?}；空串 = 清空
POST /api/pick-folder            弹原生文件夹框；取消返回 {cancelled:true}
```
